# Todo-app-Using-MySQL
Implemented CRUD operations using Todo app Using MySQL
<p>1)Firstly clone my application then run command node server to start running server.</p>
<p>2)next,in other terminal run npm start to start running my front end application</p>
   <p>3)You could now see a user interface as given in assignment</p>
   <p>4)Click on add button after creating new task and its category as High/Low/Medium .Then task is created above adding section after refreshing paghe .we can see delete  icon</p>
  on clicking it the task will be deleted after refreshing page.
  <p>5)after task is created click on check icon then that task is seen in completed section and task in completed section can be made to incomplete section on clicking on check option.</p>
  <p>6)We also have Cancel Button to delete all created tasks.</p>
  <p>7)next you can see all tasks,medium,low,high tasks by clicking on respective sections in side navigation bar.</p>
  <p>8)Hence Todo app is said to be completed using CRUD operations.</p>
